# Часть 1.

**Сетевой протокол** — это набор правил, по которым устройства обмениваются данными.

**Стек протоколов** — это набор протоколов разных уровней, которые совместно обеспечивают передачу данных по сети.

**Аналогия — отправка посылки:**
1. Подготовка: упаковать посылку и указать адрес.
2. Оформление: заполнить документы по правилам почты.
3. Перевозка: доставить посылку между городами.
4. Вручение: передать посылку получателю.

На каждом этапе действуют свои правила — как и в сетевых протоколах, где каждый уровень отвечает за определённую задачу.

# Часть 2.

| Уровень модели OSI | Основная функция | Соответствующий уровень модели TCP/IP |
|---|---|---|
| Прикладной | Сетевые службы | Прикладной |
| Представительский | Преобразование данных | Прикладной |
| Сеансовый | Управление сеансом | Прикладной |
| Транспортный | Доставка данных | Транспортный |
| Сетевой | Маршрутизация | Межсетевой |
| Канальный | Передача кадров | Доступ к сети |
| Физический | Передача битов | Доступ к сети |

# Часть 3.

| Критерий | TCP | UDP |
|---|---|---|
| Установление соединения | Требуется | Не требуется |
| Гарантия доставки | Да | Нет |
| Упорядочивание пакетов | Да | Нет |
| Контроль скорости передачи | Есть | Нет |
| Низкие накладные расходы | Нет | Да |
| Основные сферы применения | Веб, файлы, почта | Игры, стриминг, VoIP |
